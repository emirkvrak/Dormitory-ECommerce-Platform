# AsansorButik

**Proje Tanımı:**  
2. sınıfta geliştirdiğim mini çaplı bir e-ticaret sitesi projesidir. Fikir, öğrencilerin yurtlarda asansöre astıkları ilanlardan esinlenmiştir.  
Projede **HTML**, **CSS**, **C#**, **ASP.NET MVC Framework** ve **MSSQL** kullanılmıştır.
